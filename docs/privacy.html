PebbleMeet Privacy Policy

Last updated: 2026-11-22 · Maintainer: Alex Palson

PebbleMeet is an open-source Pebble smartwatch watchapp and Chrome extension that lets you control Google Meet calls and invite contacts from your wrist—without requiring a Google OAuth login by default.

1. Default Mode (Zero Google OAuth)

  • Chrome Bridge Relay: Your watch (via the Pebble mobile app) and your Chrome extension connect to a Cloudflare Workers Durable Object relay using a random 6-character pairing code. Messages (mute/camera commands, open Meet tab titles, favorite contacts, and call status) are relayed in real time in memory and are never logged or stored in a database.
  • On-device storage: Your pairing code, button preferences, optional private calendar .ics URL, and Quick Contacts are stored locally on your phone (PebbleKit JS localStorage) and in Chrome extension local storage.

2. Optional Self-Hosted Google OAuth

If you choose to connect an optional self-hosted OAuth relay, PebbleMeet requests only minimal scopes:

  • https://www.googleapis.com/auth/contacts.readonly — optional import of Google Contact names and emails so you can invite/ring them from your watch.
  • openid & email — displays which Google account is signed in.

OAuth authorization codes are exchanged on the Worker into a short-lived (90-second), single-use exchange ticket stored transiently in Durable Object storage and deleted immediately upon redemption. Tokens are never placed in URL fragments and are stored only on your phone.

3. Revoking Access & Deleting Data

Generate a new pairing code in the Chrome Extension at any time to disconnect a watch. If using optional self-hosted OAuth, tap Disconnect & Revoke in PebbleMeet Settings (which revokes the token with Google and wipes local storage) or revoke access in Google Account Permissions.

4. Open Source & Contact

Full source code is available at https://github.com/senorsunday/pebble-meet-watchapp.
